# hep-analysis Examples

Canonical worked examples in one of eight archetypes - see `agile-development`'s
[references/example-authoring.md](../../agile-development/references/example-authoring.md)
for the archetype-selection guide and how these are generated and validated
(requires `agile-development` installed alongside this skill).

| Example | Archetype | Scenario | One-line takeaway |
|---|---|---|---|
| [01-jes-systematic-cutflow.md](01-jes-systematic-cutflow.md) | Contrast | Estimating the jet-energy-scale systematic uncertainty on a cutflow-based cross-section measurement | Reusing the nominal selection mask for the JES up/down variations (reporting a suspicious 0.000% uncertainty) vs. recomputing the selection on each shifted branch (recovering the true 4.06% migration-driven uncertainty) |
| [02-tag-and-probe-background-subtraction.md](02-tag-and-probe-background-subtraction.md) | Contrast | Measuring a tag-and-probe trigger/identification efficiency with sideband background subtraction | Counting raw pass/fail window totals as pure signal (efficiency biased to 0.7761 with no uncertainty) vs. sideband-subtracting the signal yield in each category first and propagating the correlated-ratio uncertainty (0.8800 +/- 0.0143, plus a stated background-model systematic) |
| [03-li-ma-significance-iact.md](03-li-ma-significance-iact.md) | Contrast | Computing the detection significance of a candidate gamma-ray source from on/off counts in an IACT analysis | A naive Gaussian S/sqrt(B)-style formula reported as a single-trial 1.826 sigma vs. the Li & Ma (1983) likelihood-ratio significance (2.222 sigma) corrected for 25 independent scan trials (0.578 sigma globally) |
| [04-trajectory-cutflow-normalization-mismatch.md](04-trajectory-cutflow-normalization-mismatch.md) | Execution Trajectory | A signal MC cutflow yield measuring ~15% high, uniformly, at every selection step | Traces the shape-preserving excess to a `sum_full_gen_weights` denominator computed before 6 resubmitted production jobs were merged in, walked from triage through a corrected denominator to a yield matching an independent validation skim |
| [05-trajectory-systematic-template-migration-flag.md](05-trajectory-systematic-template-migration-flag.md) | Execution Trajectory | A JES Up/Down systematic template appears inverted in the highest-pt bin | Resists the tempting "just swap the labels" fix, instead finding a real copy-paste config bug in one era while confirming the one genuinely inverted bin is a real migration effect via generator-truth |
| [06-trajectory-abcd-closure-failure.md](06-trajectory-abcd-closure-failure.md) | Execution Trajectory | An ABCD background estimate fails closure in a validation region by a uniform ~20% | Traces the shortfall to a real correlation between the two discriminating variables, measures a kappa=1.20 correction factor in an independent region, and verifies it reproduces the validation observation exactly |
| [07-gated-pipeline-systematic-uncertainty-closure-gate.md](07-gated-pipeline-systematic-uncertainty-closure-gate.md) | Gated Pipeline | Estimating a b-tagging scale-factor systematic budget with a closure-test gate | Three gates - registry completeness, template-validation closure, and a red-team pass that finds a wrongly-uniform era-correlation assumption double-suppressing a calibration-statistics component |
| [08-gated-pipeline-unfolded-cross-section.md](08-gated-pipeline-unfolded-cross-section.md) | Gated Pipeline | Performing an unfolded differential cross-section measurement | Three gates - independent train/test response split, a predefined regularization stopping rule via truth injection, and a red-team pass that finds genuine truth-model dependence in the highest-pt bin and excludes it rather than hiding it |
| [09-gated-pipeline-alignment-propagation.md](09-gated-pipeline-alignment-propagation.md) | Gated Pipeline | Propagating a re-derived tracker alignment through a rigidity-spectrum measurement | Three gates - enumerating every downstream product needing re-derivation, a quantitative before/after comparison, and a red-team pass that finds one cosmic-ray comparison alone can't bound a charge-antisymmetric weak mode |
| [10-decision-tree-control-region-excess-triage.md](10-decision-tree-control-region-excess-triage.md) | Decision-Tree | An unexpected excess in a background-dominated control region | Selects the background-mismodeling branch over new-physics/detector-effect/statistical-fluctuation given a coherent nuisance pull, traces it to sideband functional-form uncertainty, and defines fallback re-triage |
| [11-decision-tree-tracking-efficiency-drop-triage.md](11-decision-tree-tracking-efficiency-drop-triage.md) | Decision-Tree | A tracking efficiency drop in a specific momentum/occupancy regime | Selects the pattern-recognition search-window branch over channel-map/alignment/validity-boundary causes, quantifies the efficiency-vs-fake-rate tradeoff, and proposes an occupancy-dependent fix |
| [12-decision-tree-multimessenger-alert-triage.md](12-decision-tree-multimessenger-alert-triage.md) | Decision-Tree | A public neutrino alert with a possible electromagnetic counterpart candidate | Selects the post-hoc-window branch requiring a trials correction, computes a trials-corrected p-value of 0.85 against the naive 0.014, and recommends reporting an unconfirmed candidate rather than a coincidence claim |
| [13-elicitation-signal-search-ambiguous-request.md](13-elicitation-signal-search-ambiguous-request.md) | Elicitation | "Can you check if there's a signal in this dataset?" - no channel, region, background model, or significance threshold named | Four clarification questions resolve the request to a dijet bump-hunt scan (1.5-6 TeV), a smoothly-falling QCD background model with a control-region validation, and a global-significance convention with a trials-factor correction |
| [14-test-first-selection-efficiency-numerical-tolerance.md](14-test-first-selection-efficiency-numerical-tolerance.md) | Test-First | A weighted selection-efficiency function must match a hand-computed reference within 1e-6 | Catches a missing shared-events covariance term in the efficiency-variance formula that overstates the reported uncertainty by 87%, red to green with an exact numerical match |
| [15-postmortem-mc-production-pipeline-crash.md](15-postmortem-mc-production-pipeline-crash.md) | Postmortem | An overnight MC-production pipeline crashes partway through, corrupting a fraction of output files | Traces silently-truncated "successful" output files through 5 Whys to a batch-pool reconfiguration that broke an implicit scratch-cleanup assumption, fixes it with an automated output-integrity gate, and adds a clean-output-file-rate monitoring rule |
