# Worked Examples

Illustrative, not verified against any named experiment, codebase, or venue template. Each
file shows: request, diagram type, assumptions, source (Mermaid/DOT/TikZ/ASCII), validation
checks, caption. Mermaid and TikZ sources were not rendered/compiled in authoring; DOT sources
were checked with `dot`. Render and inspect before publishing.

| Dir | Files |
|---|---|
| `general/` | research workflow, methodology pipeline (from a Methods excerpt), conceptual framework, experimental workflow |
| `hep/` | collider pipeline, MC chain, detector schematic, likelihood architecture, decay tree, SR/CR workflow, Feynman-style |
| `statistics/` | Bayesian workflow, hierarchical model (plates), causal DAG, MCMC, hypothesis test, bootstrap, HMM |
| `computer-science/` | microservices, Transformer, RAG, agentic AI, distributed pipeline, API sequence, database platform, ML training pipeline |

Not covered by a standalone example: repository architecture extraction (read the repo first; see
`../references/computer-science.md`).
