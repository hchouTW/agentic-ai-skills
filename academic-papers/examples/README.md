# academic-papers Examples

Canonical worked examples: a "Common Weak Approach" vs. "Expert-Level Best
Practice" contrast plus key takeaways, for a realistic scenario in this skill's
domain. See `agile-development`'s
[references/example-authoring.md](../../agile-development/references/example-authoring.md)
for how these are generated and validated (requires `agile-development`
installed alongside this skill).

| Example | Domain Use Case | Contrast in one line |
|---|---|---|
| [01-referee-response-significance-claim.md](01-referee-response-significance-claim.md) | Responding to a referee report that questions a statistical-significance claim | Restating the original 3.5σ claim with no calculation and no manuscript change vs. quoting the comment, computing the look-elsewhere-corrected 2.6σ global significance, and pointing to the exact revised text |
| [02-related-work-synthesis.md](02-related-work-synthesis.md) | Synthesizing a related-work section from a stack of papers instead of listing them | An annotated-bibliography paragraph summarizing five papers in isolation with no comparison vs. a methodologically-grouped synthesis that states each prior method's flaw, names a precise coverage gap, and ties the new contribution to it with a number |
| [03-citation-claim-verification.md](03-citation-claim-verification.md) | Verifying that a citation actually supports the specific numeric claim attached to it before submission | Approving a citation after an abstract-level topic match vs. tracing the claim to its source passage, finding the number is unsupported as stated, and propagating the corrected value through the downstream rate prediction |
