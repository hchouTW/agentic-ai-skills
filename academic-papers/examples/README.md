# academic-papers Examples

Canonical worked examples in one of eight archetypes - see `task-authoring`'s
[references/example-authoring.md](../../task-authoring/references/example-authoring.md)
for the archetype-selection guide and how these are generated and validated
(requires `task-authoring` installed alongside this skill).

| Example | Archetype | Scenario | One-line takeaway |
|---|---|---|---|
| [01-referee-response-significance-claim.md](01-referee-response-significance-claim.md) | Contrast | Responding to a referee report that questions a statistical-significance claim | Restating the original 3.5σ claim with no calculation and no manuscript change vs. quoting the comment, computing the look-elsewhere-corrected 2.6σ global significance, and pointing to the exact revised text |
| [02-related-work-synthesis.md](02-related-work-synthesis.md) | Contrast | Synthesizing a related-work section from a stack of papers instead of listing them | An annotated-bibliography paragraph summarizing five papers in isolation with no comparison vs. a methodologically-grouped synthesis that states each prior method's flaw, names a precise coverage gap, and ties the new contribution to it with a number |
| [03-citation-claim-verification.md](03-citation-claim-verification.md) | Contrast | Verifying that a citation actually supports the specific numeric claim attached to it before submission | Approving a citation after an abstract-level topic match vs. tracing the claim to its source passage, finding the number is unsupported as stated, and propagating the corrected value through the downstream rate prediction |
| [04-trajectory-referee-report-to-cover-letter.md](04-trajectory-referee-report-to-cover-letter.md) | Execution Trajectory | Walking a three-comment referee report through triage, revision, and a resubmission cover letter | Triages each comment differently (fix, fix, factual pushback) instead of answering uniformly, with a literal manuscript diff and a `check_manuscript.py` pass verifying the changes landed |
| [05-trajectory-reproducibility-audit-config-mismatch.md](05-trajectory-reproducibility-audit-config-mismatch.md) | Execution Trajectory | Auditing whether a paper's headline fitted slope reproduces from the authors' released code and data | Traces an initial rerun mismatch to a released config that omits the inverse-variance weighting the paper's own Methods section describes, and reports the discrepancy rather than silently patching the authors' repository |
| [06-trajectory-notation-inconsistency-audit.md](06-trajectory-notation-inconsistency-audit.md) | Execution Trajectory | A co-author flags a possibly-reused symbol in a late-manuscript equation | Builds a symbol ledger to confirm σ is genuinely redefined (not a convention difference), fixes the label, and numerically verifies the abstract's quoted significance is unchanged by the fix |
| [07-gated-pipeline-manuscript-submission.md](07-gated-pipeline-manuscript-submission.md) | Gated Pipeline | Preparing and submitting a cross-section measurement manuscript to a target physics journal | Three gates - concrete gap formulation against the submission checklist, a draft closing every gap by name, and a self-refereed red-team pass that upgrades a folded-in systematic from negligible to a Major concern before the submit gate |
| [08-gated-pipeline-grant-proposal-nsf-style.md](08-gated-pipeline-grant-proposal-nsf-style.md) | Gated Pipeline | Drafting an NSF-style research proposal under a page-limited Specific Aims format | Three gates - trimming preliminary results and sourcing real budget figures, drafting against the funder's actual criteria, and a red-team pass that catches a still-generic Broader Impacts claim before submission |
| [09-gated-pipeline-thesis-by-publication-assembly.md](09-gated-pipeline-thesis-by-publication-assembly.md) | Gated Pipeline | Assembling a thesis-by-publication from three papers at different publication stages | Three gates - per-paper copyright/status/contribution gaps, connective material that synthesizes rather than lists, and a red-team pass that finds a real cross-paper notation clash needing a reconciling footnote |
| [10-decision-tree-referee-comment-triage.md](10-decision-tree-referee-comment-triage.md) | Decision-Tree | Triaging a batch of referee comments into the right response category before drafting replies | A 5-row matrix (analysis gap / clarification / defensible choice / typo / out-of-scope) selects a genuine-gap branch for a period-split request, verifies no run-dependent effect, and defines fallback re-triage if a real effect had been found instead |
| [11-decision-tree-systematic-review-screening.md](11-decision-tree-systematic-review-screening.md) | Decision-Tree | Screening a retrieved record against a pre-registered systematic-review protocol | Selects the retrieval-limitation branch for an unobtainable conference abstract, keeping it out of both the include and exclude counts, with fallback re-triage if the full text later surfaces or a duplicate is found |
| [12-decision-tree-erratum-corrigendum-classification.md](12-decision-tree-erratum-corrigendum-classification.md) | Decision-Tree | Classifying a post-publication error report into the correct correction mechanism | Selects the corrigendum branch (error present in the accepted manuscript, not production) for a double-counted acceptance correction, with worked before/after arithmetic and fallback re-triage to erratum or no-correction-needed |
| [13-elicitation-improve-paper-before-submission.md](13-elicitation-improve-paper-before-submission.md) | Elicitation | "Can you make my paper better before I submit it?" - no target venue, deadline, resubmission status, or co-author scope named | Four clarification questions resolve the request to a fresh Physical Review D submission within one month, ready for co-author circulation, with an explicit pre-submission checklist scope |
| [14-elicitation-related-work-section-request.md](14-elicitation-related-work-section-request.md) | Elicitation | "Can you write the related work section?" - no target length, competing papers, or gap framing named | Resolves to a ~1-page section compressing two adjacent-final-state papers to one clause each and stating the novelty gap per the reference doc's gap-pattern taxonomy, not exhaustive Zotero-library coverage |
| [15-elicitation-reviewer-response-request.md](15-elicitation-reviewer-response-request.md) | Elicitation | "Can you respond to the reviewers?" - no round, format, contested-comment stance, or deadline named | Resolves to a point-by-point response letter with exact table/figure pointers for one report, explicitly not re-opening two reports the author team already considers addressed, within an 8-day deadline |
| [16-adversarial-audit-statistical-significance-derivation.md](16-adversarial-audit-statistical-significance-derivation.md) | Adversarial Audit | A manuscript's derivation of a stated statistical-significance claim (5.0σ combined discovery) | Attacks an uncorrected look-elsewhere effect (contradicted by the manuscript's own Methods section) and an unjustified independence assumption in a two-channel Fisher combination, dropping the honest claim to 3.91σ evidence |
| [17-adversarial-audit-reproducibility-claim.md](17-adversarial-audit-reproducibility-claim.md) | Adversarial Audit | A reproducibility statement claims `make all` "regenerates Table 2 and Figure 3 exactly" | Two attack vectors - an undisclosed manual post-processing step and an unpinned dependency range - closed by an automated pipeline matching Table 2 and a hard version pin that fails loudly instead of silently drifting |
| [18-adversarial-audit-literature-review-coverage-claim.md](18-adversarial-audit-literature-review-coverage-claim.md) | Adversarial Audit | A related-work opening claims "comprehensive review... no existing method addresses" the paper's setting | Two attack vectors - a missed prior paper that already addresses the claimed gap, and a vague, unfalsifiable differentiation claim - closed by citing the prior work and naming the concrete architectural difference |
| [19-test-first-citation-checker-invariant.md](19-test-first-citation-checker-invariant.md) | Test-First | A citation checker must flag every dangling `\cite` key when no `.bib` file is found at all, and not flag a key present in both | Red run shows a missing-`.bib` case silently printing "No issues found"; Green run's fixed short-circuit correctly flags all dangling keys |
| [20-test-first-latex-unresolved-ref-invariant.md](20-test-first-latex-unresolved-ref-invariant.md) | Test-First | A manuscript checker must fail loudly on an unresolved `\pageref{}` target instead of silently rendering "??" | Red run shows `\pageref` targets slipping past `REF_RE`; Green run's extended regex catches the unresolved target before it reaches a reviewer |
| [21-test-first-word-count-limit-invariant.md](21-test-first-word-count-limit-invariant.md) | Test-First | A word-count checker must classify a rebuttal against a venue's strict limit, counting footnotes but excluding the bibliography | Red run shows a 51-word-over rebuttal misreported as compliant at 31 words; Green run's footnote-inclusion fix reports the true, over-limit count |
| [22-postmortem-stale-reference-list-submission.md](22-postmortem-stale-reference-list-submission.md) | Postmortem | A submitted manuscript's official PDF cites the wrong paper because the venue's auto-compile pulled a stale, precompiled reference list | 5 Whys trace to a detection step that logged the mismatch but never notified an author; fix adds a pre-submission timestamp gate and a required post-upload bibliography diff |
| [23-postmortem-equation-edit-consistency-break.md](23-postmortem-equation-edit-consistency-break.md) | Postmortem | A co-author's last-minute variable substitution in one equation was never propagated to a later equation, discovered only after submission | 5 Whys trace to a one-time notation audit never re-triggered after a late edit; fix blocks any equation-touching commit within 120 minutes of deadline until the audit is clean |
| [24-postmortem-private-repository-data-statement.md](24-postmortem-private-repository-data-statement.md) | Postmortem | A posted preprint's data-availability statement pointed to a still-private repository, blocking reviewers and readers for days | 5 Whys trace to a release checklist that never verified a promised link actually resolves; fix adds a required pre-posting gate that checks every data-statement URL returns HTTP 200 |
