## Test specification notes (possible mis-specification)

1. **T43, critical requirement 2** ("the 3.0 is the flat-prior Bayesian or the B=0 value"): this is incomplete. For N = 0, the CLs limit is exactly -ln(1-CL) = 3.0 for every B, because CLs = e^{-(s+b)}/e^{-b} = e^{-s}. So under CLs, the colleague's "3.0 whatever the background is" is exactly right. Both T43 answers found this, and T43_A recommends asking which construction the colleague means. The requirement should add "or the CLs value at N = 0 (exactly B-independent)". Otherwise a grader could penalize an answer that correctly concedes the colleague's point for CLs. The prohibited claim is correctly scoped to the classical limit and is unaffected.
2. **T42, critical requirement 2** ("classical Poisson limit may be zero or not meaningful when N is below B"): for N = 3 and B = 4.2, the classical limit is 3.55, which is positive and well defined. It is not zero. The real issue is that it lies below the expected sensitivity (median 5.79) and has no protection against downward fluctuations. The wording "may be zero" comes from the general reference text and does not fit this test's inputs. Suggested rewording: "classical limit (3.55) is tighter than the expected sensitivity because N < B, and is not a result by itself". Both answers satisfied the intended meaning.
3. **T42, critical requirement "seed and toy count recorded for toy numbers"**: every T42 number is deterministic (`upper-limit`, `fc-interval` grid, `cls-limit` quantile nodes), so the requirement can only be met vacuously. T43 is where toy numbers appear naturally (`profile-limit`, `neyman-limit`), but T43 does not list this requirement. Consider moving it to T43 or duplicating it there. Under that requirement, both T43 answers would lose the toy count on at least one value.
4. **Script default (not a test defect, but relevant to T42/T43)**: `poisson_diagnostics.py fc-interval` defaults to `--cl 0.9`, unlike `upper-limit` and `cls-limit`, which default to 0.95. A user who omits `--cl` gets a 90% FC interval next to 95% CLs and classical limits. Consider defaulting to 0.95, or printing a warning when CL is not given.
