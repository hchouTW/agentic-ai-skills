## CRDB (LPSC Grenoble), https://lpsc.in2p3.fr/crdb/

[Documented, S50, C125-C128; the page was read on 2026-10-02 by the skill maintainer, not by me.]

- It compiles published cosmic-ray data from 10^6 to 10^21 eV: leptons, nuclei (isotopes, elements, groups), antinuclei and dipole anisotropy.
- The page stated V4.2 (September 2026) with 143 experiments from 614 publications. Counts change with each release, so record the version and date of anything you extract.
- Access is by the website, a REST interface, or the pip-installable `crdb` Python library. Exports are in USINE, GALPROP and csv formats.
- The REST parameters are `num`, `den`, `energy_type`, plus optional `exp_dates`, `combo_level`, `energy_convert_level` and `time_series`.
- The v4.1 abstract says it includes AMS-02 and PAMELA time series. Whether these agree with the AMS papers was not checked.

## How to run the cross-check

1. Fix the estimand and variable. The 2015 proton flux is in rigidity (GV). Query the databases on the same axis and do not convert. If you must convert to kinetic energy or energy per nucleon, state |Z|, A and the mass.
2. For CRDB, use a native-axis query restricted to AMS: `exp_dates=AMS`, `combo_level=0`, `energy_convert_level=0`. For a proton, set `num=H` and `energy_type=R`. This is an untested [General method] example following the page's REST parameters.
3. Map each returned `SUBEXP_NAME` to its AMS paper by name and data-taking range. Check that period and rigidity range match the paper (1 GV-1.8 TV, 2011-05-19 to 2013-11-26 for S06).
4. Compare value, bins and uncertainty with the paper's table. Where they differ, the paper wins. Possible causes are transcription from a plot (`PUBLI-DATAORIGIN` records table versus plot), rebinning, or a different analysis or data period. Report real discrepancies to the database maintainers.
5. Write a metric and a trigger instead of "agrees". For example, state a per-bin relative difference against the quoted total uncertainty, and the difference at which you would investigate.

## Pitfalls

- **Datasets differ.** CRDB holds several AMS proton datasets (time-averaged, per Bartels rotation, daily). Time series are excluded by default (`time_series=no`). Do not merge or average datasets.
- **Systematics.** A CRDB systematic of 0 means "not separately quoted". It is not an AMS statement. Take AMS systematics from the paper.
- **Combos.** Combos and conversions are formed at query time and add errors in quadrature. A returned ratio may be a combination of two native fluxes, not a published ratio.
- **Version and date.** Record the CRDB version and retrieval date. Cite the CRDB papers (S51) and, for each dataset used, its primary AMS paper. For SSDC, cite the 2017 proceedings (S53) and say the page was not read.
- **Currency.** The skill's index was last verified 2026-09-20. I did not check for newer AMS proton papers or supplements, since I had no web access.
