Defects, in priority order:

1. **The trigger efficiency is probably counted twice.** You say the response matrix already includes efficiency. If that efficiency includes the trigger, which is the usual convention, multiplying in a separate trigger efficiency corrects the same effect again. Either the matrix is defined with trigger efficiency inside and you apply nothing more, or the matrix is a pure migration (efficiency-free) and the efficiencies are applied explicitly once. Decide where each effect lives and write it down. Give each effect one `effect_id`, and list `response.includes` and `estimator.applies` so no effect appears in both.

2. **The TRD gain drift is corrected twice.** A run veto and an efficiency correction for the same drift are the same correction in two categories (veto/quality selection and efficiency). The run veto changes the livetime and exposure, because vetoed time is removed. The efficiency correction then has to be measured only on the retained runs. If the veto removes the bad periods, the efficiency should hold only the residual, validated drift, not the drift again. Choose one treatment and give the other a closure check. Do not also add the drift as a systematic.

3. **Livetime and exposure are not independent factors.** Exposure already contains acceptance, livetime and the geomagnetic transmission (m² sr s), so "livetime × exposure" counts livetime twice. Use either `Φ = (N - b) / (A_eff · T_live · ΔR)` or `Φ = (N - b) / (Exposure · ΔR)`, never both. The run veto from (2) must be applied to T_live in the same way as to the numerator.

4. **The bare N - b with a response matrix is the wrong estimator.** If the response matrix is applied, the observed counts are not corrected bin by bin. Either unfold with forward folding or regularized unfolding (the response is applied to the signal model, and b is a modeled expectation), or use a bin-by-bin correction with the unfolding effect inside the efficiency. Both are not valid at once. Subtracting b first is also wrong if b has its own uncertainty, or if N is small; propagate b as a nuisance parameter with a Poisson/template likelihood, not a Gaussian subtraction.

5. **Do not multiply conditional efficiencies as if independent.** The trigger, selection and reconstruction efficiencies are correlated, so measure each conditionally on the previous cuts in data, or take the total from MC with data/MC corrections.
