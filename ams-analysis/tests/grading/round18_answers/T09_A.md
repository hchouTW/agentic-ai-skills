**[General method]** Assumptions: |Z| = 2, A = 4 (He-4), rest energy m c² = 3.7274 GeV (PDG-level nuclear mass), R = 20 GV taken as given; charge sign is not used. Values come from `scripts/ams_kinematics.py` for this exact input.

- Momentum: p = |Z|·R/c, so pc = 2 × 20 = **40.0 GeV/c**. This is not 20: rigidity is momentum per unit charge.
- Total energy: E = sqrt((pc)² + (mc²)²) = sqrt(40² + 3.7274²) = **40.173 GeV**.
- Kinetic energy: T = E − mc² = 36.446 GeV.
- Kinetic energy per nucleon: T/A = 36.446 / 4 = **9.111 GeV/n**.

Notes: the T/A value assumes pure He-4 (A = 4). For elemental helium, a ³He admixture changes A and the mass, so T/A at a given R carries an isotope-composition uncertainty. This is arithmetic only, not an AMS-measured quantity. If you convert a binned flux, the Jacobian is needed: the point value dR/d(T/A) at this R is about 2.009 GV per GeV/n, and bin edges must be converted, not just relabeled.
