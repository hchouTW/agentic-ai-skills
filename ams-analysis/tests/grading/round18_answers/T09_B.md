**[General method]** Assumptions: |Z| = 2, A = 4, rest energy m c² = 3.7274 GeV (He-4 nuclear mass, PDG-level; adopted from the skill's reference list). Values come from `scripts/ams_kinematics.py` for exactly this input. Rigidity is not momentum, so the conversion goes through p = |Z|R.

- Momentum: p c = |Z| R = 2 × 20 GV = **40.0 GeV** (p = 40 GeV/c)
- Total energy: E = sqrt((pc)² + (mc²)²) = sqrt(40² + 3.7274²) = **40.173 GeV**
- Kinetic energy: T = E − mc² = **36.446 GeV**
- Kinetic energy per nucleon: T/A = 36.446 / 4 = **9.111 GeV/n**

Caveats: these numbers hold only for helium-4. For He-3 (A = 3, mc² = 2.8084 GeV) the same rigidity gives a different T/A, so the elemental-to-T/A conversion needs a stated A or isotopic composition. If a binned flux is converted rather than a single point, a Jacobian and bin-edge treatment are needed (the point Jacobian dR/d(T/A) here is about 2.009 GV per GeV/n). Charge sign is not used in this conversion. No AMS-specific measured numbers are quoted.
