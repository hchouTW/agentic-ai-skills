**Short answer.** With n = 3 observed and b = 4.2 expected (no signal excess; a downward fluctuation), the 95% CL upper limit on the signal counts depends on the construction. Pick one in advance, state it, and show the others as cross-checks. All numbers below are [General method], from `scripts/poisson_diagnostics.py`, and assume b = 4.2 is known exactly (user-supplied).

| Construction | 95% upper limit on s (counts) | Notes |
|---|---|---|
| Classical one-sided Poisson, P(N<=3 \| s+b) = 0.05 | 3.55 (total mean 7.75 minus 4.2) | Valid but can be tiny or negative if n fluctuates low; no expected sensitivity |
| Feldman-Cousins unified (95%) | [0, 4.18] | Two-sided unified interval; lower bound 0 is expected behaviour, not a failure. It is an interval, not a CLs limit |
| CLs (Read/Junk) | 4.90 observed | Conservative by design (over-covers); not a frequentist confidence statement |

**What I would quote.** Quote the CLs limit, s < 4.9 events at 95% CL (CLs), together with its expected sensitivity. The median expected limit under background only is 5.79, with a 1-sigma band of 4.14 to 7.90 and a 2-sigma band of 3.51 to 11.53. The observed limit (4.9) lies inside the 1-sigma band, slightly better than the median, so the result is a mild downward fluctuation and not an anomalously strong limit. State that CLs is a convention that over-covers. Add the classical (3.55) and FC (4.18) numbers as a table so readers can compare; do not label one construction as another. Do not quote only the classical 3.55 as if it were the sensitivity: it would be much tighter than what the experiment could typically exclude (about 5.8).

**Do not** use S/sqrt(B), Gaussian errors or Wilks at n = 3: counts are small.

**How to show it.**
1. State the construction: one-sided, 95% CL, test statistic, known versus uncertain background, CLs or not.
2. Plot or tabulate the observed limit with the expected-limit median and 1/2-sigma band (the Brazil-band style), next to the three constructions above.
3. The background b = 4.2 is treated as exactly known. If it carries an uncertainty sigma_b (it almost certainly does), redo with a profile-likelihood or CLs-with-sigma_b construction and toy calibration, and report how much the limit moves as sigma_b varies. That is a systematic on the method.
4. Record the seed and toy count for any toy-based number.
5. Convert counts to a flux or rate limit only through exposure: Phi_UL = N_UL / (E * Delta x), where E (acceptance x livetime x efficiency, as a single exposure, not multiplied twice) carries its own uncertainty as a nuisance, including any correlation with the background model. If the limit is on a rare AMS species, the signal efficiency enters here, and the efficiency tail validation applies.
6. Report separately: candidates (events passing all criteria), excess (none here: n < b), evidence, discovery. This is a limit, not a detection.

**Inputs that would change the answer:** whether b = 4.2 has an uncertainty and how it was estimated (control region, MC, data-driven); one bin or several (shape information tightens a limit); the signal efficiency and exposure (to get a flux limit); whether the analysis is pre-registered for a particular construction.
