## Crystal Ball fit to a dimuon mass peak in RooFit [General method]

Setup: a Gaussian core with a power-law tail on one side. Use it for the low-mass tail from final-state radiation and resolution effects.

```cpp
using namespace RooFit;
RooRealVar m("m","m_{#mu#mu} [GeV]",80,100);          // set the range to your peak region
RooRealVar mean ("mean","mean",91.19,85,95);
RooRealVar sigma("sigma","sigma",1.5,0.3,5);
RooRealVar alpha("alpha","alpha",1.5,0.1,5);          // transition point, in units of sigma
RooRealVar n    ("n","n",3,0.5,50);                   // tail exponent
RooCrystalBall cb("cb","CB",m,mean,sigma,alpha,n);    // ROOT >= 6.20; older: RooCBShape
// add a background, e.g. exponential, for a real dataset:
RooRealVar tau("tau","tau",-0.05,-1,0);
RooExponential bkg("bkg","bkg",m,tau);
RooRealVar nsig("nsig","nsig",1e4,0,1e7), nbkg("nbkg","nbkg",1e3,0,1e7);
RooAddPdf model("model","model",RooArgList(cb,bkg),RooArgList(nsig,nbkg));

auto res = model.fitTo(data, Extended(true), Save(true), PrintLevel(-1)); // use SumW2Error(true) or AsymptoticError(true) for weighted data
res->Print("v");
// the tail parameters are alpha.getVal()/alpha.getError() and n.getVal()/n.getError()

auto fr = m.frame();
data.plotOn(fr);
model.plotOn(fr);
model.plotOn(fr,Components(cb),LineStyle(kDashed));
model.paramOn(fr);
fr->Draw();
```

Notes on the tail parameters:

- `alpha` sets where the tail starts, at `mean - alpha*sigma` for the standard left tail. `n` sets the power-law steepness.
- `n` and `alpha` are strongly correlated, and `n` is poorly constrained if few events populate the tail. Check `res->correlationMatrix()` and the profile likelihood. A common fix is to fit the tails on simulation (or a high-statistics control sample), fix or Gaussian-constrain them, and float only `mean` and `sigma` on data.
- If `n` runs to its upper bound, the tail is effectively unconstrained or the data are nearly Gaussian. Widen the bound or fix `n` (for example at 5 or 10). Don't interpret the value.
- Report the fit as `alpha` and `n` with their errors, taken from the fit covariance (HESSE) or from MINOS if the likelihood is asymmetric. Check `res->status()` and `covQual()`.
- To model both tails, use `RooCrystalBall` with the double-sided constructor (`sigmaL`, `sigmaR`, `alphaL`, `nL`, `alphaR`, `nR`). For a true resonance with natural width (Z, J/psi), convolve a Breit-Wigner with the CB (`RooFFTConvPdf`) or use a Voigtian core. Otherwise `sigma` absorbs the width and is no longer pure resolution.
- Validate the fit:
  - Use a binned or unbinned fit consistently, and keep the fit range wide enough to constrain the background.
  - Check pulls or chi2/ndf, which is a diagnostic only for binned fits.
  - Run toy MC to test bias in the tail parameters, and test the sensitivity to fit range and background model.
  - Plot on a log scale to see the tail.
