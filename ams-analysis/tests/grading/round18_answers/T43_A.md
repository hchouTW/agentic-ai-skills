**Short answer: your colleague is right only under specific conventions, and "whatever the background is" is not true in general. It depends on which construction you use.** [General method throughout; no AMS numbers are involved, and 0.5 events and 30% are your inputs.]

**Where 3.0 comes from.** For n_obs = 0 the Poisson probability of seeing zero is exp(-(s+b)). Setting it to 0.05 gives s+b = -ln(0.05) = 2.996, which is about 3.0.

**What happens to the limit as the background changes**
- **Classical (frequentist) limit with known b:** s_UL = -ln(0.05) - b. For b = 0.5 this is 2.50 (script output 2.4957). It shrinks as b grows and is not positive once b reaches 3.0. So it is not independent of the background. Your colleague is wrong for this construction.
- **CLs limit:** CLs = CL(s+b)/CL(b) = exp(-s), so for n = 0 the limit is 3.00 for any b. This is the sense in which "3.0 whatever the background" is correct. The script gives 2.996 at b = 0.5, and it stays 2.996 when I marginalize a background uncertainty of sigma_b = 0.15. CLs is conservative by design: it over-covers and is not a frequentist interval. Quote it with that label, and report the expected sensitivity next to it. The script's median expected limit is 3.0, with a +1 sigma band edge of about 4.4.
- **Bayesian limit with a flat prior on s:** this also gives 3.0, independent of b, but it answers a different question (a credible interval, not coverage).
- **Feldman-Cousins (unified interval):** for n = 0, b = 0.5, 95% CL the upper bound is 2.63 (grid-scan accuracy about 0.005). It stays at 2.62 when I marginalize sigma_b = 0.15. It is neither 3.0 nor 2.50, and it never goes empty or negative.

So the answer is "3.0" if you use CLs or a flat-prior Bayesian limit, and "2.5-2.6" if you use a classical or FC construction. You must state which one you use.

**What to do about the uncertain background (0.5 +/- 30%, so sigma_b about 0.15)**
1. **Pick the construction first** and say so in the paper: classical, FC, CLs or profile likelihood. Report the confidence level and whether the limit is one-sided.
2. **Treat the background as a nuisance, not a fixed number.** Use a profile-likelihood or toy-calibrated construction, or a Cousins-Highland marginalization. State how the 30% was derived (data-driven, MC, or control region). It should be an auxiliary measurement, not a prior chosen by convenience. It should not come from the signal region you are fitting.
3. **Check the sensitivity to sigma_b.** Vary it (for example 0, 15%, 30%, 100%) and show that the limit hardly moves. With n = 0 and b = 0.5 it barely does. For the CLs limit it does not move at all. FC moves by about 0.01 (2.63 to 2.62). A marginalized result is an approximation, so compare it with a profile construction. For a single-bin background nuisance, the Berger-Boos construction gives guaranteed coverage.
4. **Do not trust the asymptotic profile limit at zero counts.** The script gave 1.35 asymptotic against a toy-calibrated 2.67 (seed 1, 4000 toys). That is a factor of about 2, so use the toy-calibrated value. The profile limit has no CLs protection: with zero observed events and low background it can exclude signals the experiment has little power to test. Report the expected sensitivity too.
5. **Run a coverage check with seeded toys.** Record the seed, toy count and confidence level.
6. **Do not let a 0.5-event background drive the answer.** At 0.5 events the tail matters more than the 30%. For an antinucleus (for example He to anti-He) the dominant background is a charge-confusion tail, not a Gaussian-core estimate. Validate it with abundant matter samples under loose cuts and extrapolate to the tight selection, and treat the tail probability as the nuisance. The 30% may be too small, so test a larger uncertainty.
7. **Convert counts to a flux or ratio limit** only through the exposure: Phi_UL = N_UL / (E * Delta x). Propagate the exposure and efficiency uncertainty as nuisances.
8. **Wording.** Zero observed candidates is a limit, not a measurement. Predefine the blinded region and the reporting thresholds. Do not infer anything beyond the numbers supplied.
