**Verdict: not acceptable as described.** Two separate problems, either of which can bias or mis-size the fitted index. Both are [General method]; no AMS-specific number is involved.

**1. Diagonal errors on unfolded points are wrong for a fit.**
Unfolding (Tikhonov especially) makes neighbouring unfolded bins correlated. The response inverse spreads each reconstructed bin's fluctuation over several truth bins, and regularization adds smoothing correlations. The full covariance of the unfolded result has sizeable off-diagonal terms, often with strongly negative adjacent-bin correlations when regularization is weak. A chi2 or likelihood fit that uses only the diagonal:
- gets the wrong index uncertainty, which can be too small or too large;
- gets a chi2/ndf that is meaningless, so the goodness of fit cannot be trusted;
- can also shift the index, because the weights are wrong.

Use the full unfolded covariance, and check that it is positive semi-definite. It should combine the data covariance with the response covariance from finite MC statistics. If the response is a finite MC sample, add that response covariance as a full matrix (multinomial or replica-based), not a diagonal. Treat shared systematics (acceptance, efficiency, scale, resolution tails) as correlated nuisances, not as independent per-bin errors. Quoting per-bin percentage errors as if they were independent is a listed failure mode.

**2. The regularization strength was picked automatically at the L-curve corner.**
- The L-curve corner (maximum curvature) is a heuristic. It is not a statistically principled criterion, and it is often not a safe automatic rule: its error on toys is often well above that of the best fixed setting.
- Tikhonov pulls the result toward the smoothness the penalty prefers. A power-law index is a smoothness property, so the fitted index can inherit the regularization bias. This is a bias-variance trade-off, and the index depends on the chosen strength.
- Choosing the strength from the data makes the unfolded points and their covariance data-dependent, so the covariance does not include that choice.

**What I would do** [Proposal]:
1. Fix the regularization strength by a stated criterion, not from the scan's own minimum (which is circular). For example, choose the strength at which closure bias on a different truth is below a stated fraction of the statistical sigma and no adjacent-bin correlation is below a stated value. Compare the L-curve, generalized cross-validation and leave-one-out cross-validation on toys before trusting any one. The thresholds are my proposals, not AMS values.
2. Run closure tests (nominal, reweighted and distorted truth spectra, response perturbations) and pulls on Poisson-fluctuated pseudo-experiments. Trigger a method change or an added uncertainty if the pull width is above 1 or the mean pull is beyond about 3 standard errors.
3. Fit the index with the full covariance, and propagate the regularization choice by varying it, and the prior or truth model, as a systematic on the index.
4. Preferably fit the index directly by forward folding: fit a parametric spectrum, folded through the response, to the reconstructed counts with a Poisson likelihood. That avoids the correlated-points and regularization-bias problem. Compare it with unfold-then-chi2 on the same toys (the `fold-compare` mode of `scripts/unfolding_diagnostics.py`), which reports each method's bias and spread.
5. First check whether unfolding is needed at all. If migration is negligible for your precision and steepness, a diagonal-response estimator may do. A steep spectrum with finite resolution usually has non-negligible migration, so test it with the response matrix.

If the unfolded spectrum is to be published, also give the full covariance (or a replica set) so that others can fit it correctly.

**Inputs that would change this verdict:** whether you have the full unfolded covariance, including the response and systematic parts; the resolution and migration relative to the bin width, and the spectrum steepness; how the regularization varies in toys; and the rigidity range and species, which set the tails.
