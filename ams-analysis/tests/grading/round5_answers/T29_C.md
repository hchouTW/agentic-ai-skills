# Measurement brief: ⁴He flux, 2 GV – 3 TV, from public AMS data

**Estimand.** Differential ⁴He flux `Φ(R)` at the top of the instrument (m⁻² sr⁻¹ s⁻¹ GV⁻¹), per rigidity bin, for downward-going primary ⁴He with rigidity above the geomagnetic-cutoff criterion, over 2 GV–3 TV. Not corrected to the local interstellar spectrum unless a solar-modulation model is applied and stated. [General method]

**Target / level.** `target = flux`, `level = flux` (top-of-instrument).

**Species.** Helium-4: `abs_Z = 2`, `A = 4`, `charge_sign = +1`, `mass ≈ 3.7274 GeV` (reference rest energy) [General method].

**Variable, unit, range, bins.** `rigidity`, GV, `[2, 3000]`. Exact bin edges are an analysis choice — not fixed here [Unresolved].

**Data/MC scope and period.** `sample = public`; data-taking period and livetime are not fixed in this brief [Unresolved]. MC generation record/version: user-supplied [Unresolved].

**Subsystem roles.** Tracker: rigidity, charge sign, `|Z|=2` (only charge-sign source). TOF: direction, `β`, trigger, `|Z|`. RICH: `β`, `|Z|`, needed for any isotope-resolved statement. ACC: side-entry veto. [General method, per detector-and-observables]

**Public vs. user-supplied — the key scope issue for "⁴He" specifically.**
[Documented, C59, S07/S11] AMS's public **total helium** flux covers 1.9 GV–3 TV (S07, "Precision Measurement of the Helium Flux, 1.9 GV–3 TV"), selecting tracks through L1–L9 with `|R| > 1.2×IGRF cutoff` (scanned 1.0–1.4 as a systematic).
[Documented, C09, S12] AMS's public **isotope-separated** ⁴He flux only covers **2.1–21 GV** (100M ⁴He events; ³He covers 1.9–15 GV, May 2011–Nov 2017); above that range no public AMS analysis separates ³He from ⁴He.
Consequence: a true ⁴He-only flux across the full 2 GV–3 TV range **cannot be assembled entirely from published AMS isotope results**. Below ~21 GV, use the S12 isotope-separated flux directly. Above ~21 GV, "⁴He flux" must be built from the total-He flux (S07) under an **assumed isotope composition** (extrapolating the measured ³He/⁴He rigidity dependence, documented only up to 21 GV, C09/C86) — this is a **[Proposal]**, not a measurement, and its uncertainty must be propagated and stated as a distinct, fully-correlated systematic above the isotope-separation range.

**Selections** (ledger; see [reconstruction-and-data-quality](reconstruction-and-data-quality.md#cut-flow-ledger) schema): `downward_primary` (track + rigidity above `SF×cutoff`; conditional denominator: events with a reconstructed tracker track); `charge_consistency` (`|Z|=2` consistent across Tracker/TOF/RICH at multiple depths; conditional denominator: events passing `downward_primary`). Each needs a named validation metric/threshold/action (e.g. data/MC efficiency ratio in a control sample).

**Backgrounds** (see [efficiency-acceptance-backgrounds](efficiency-acceptance-backgrounds.md#background-ledger)): adjacent-`Z` migration (Z=1, Z=3 leaking into the Z=2 sample via charge-estimator tails and upstream fragmentation; control: loosened charge-consistency sample; closure via injected contamination); the ³He-in-"⁴He" contamination described above, which has **no control region above ~21 GV** from public data alone.

**Efficiency / acceptance / livetime / response — kept distinct.** Conditional trigger and charge-selection efficiencies with data/MC scale factors; effective acceptance from the MC generation record; livetime and geomagnetic transmission per bin (bin-dependent at low rigidity); response matrix `R_ij` with migration (charge-migration `Z`-matrix included). [General method, per the flux blueprint] Given the 3-decade rigidity span and a steeply falling spectrum, the **diagonal estimator is invalid**; use unfolding or forward folding, validated by closure (the flux blueprint gives phosphorus migration as large as +25%/−21% at range edges as an illustration of scale, C30 — not a He number).

**Inference.** Response-model estimator; unfolding/forward folding; low-count regions (near 3 TV) need Poisson-exact or toy-validated intervals, not Gaussian/`S/√B`.

**Validation.** MC closure (truth recovery); time/geometry/cut stability; comparison with the published total-He flux (S07) as plausibility only (agreement is not proof).

**Open inputs (unresolved).** Exact bin edges; data-taking period/livetime; acceptance, efficiency and response-matrix values (not public beyond paper figures); systematic sizes; the isotope-composition model and its uncertainty above ~21 GV; validated cutoff safety factor for this exact selection.
